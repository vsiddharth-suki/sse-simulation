This page is the app. It only connects and shows what arrives. Statuses appear on their own.

  • This page is the client (the Suki app).
  • nginx on port 8080 is ms-gateway. It forwards the stream and can cut a quiet connection.
  • The Node server behind nginx is ms-notifications. It holds the open stream.
  • A timer in that server is ms-jobber. Every few seconds it reports an ambient note status.
